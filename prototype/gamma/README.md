# ガンマ計算プロトタイプ

`index.html` をブラウザで開くと、体重と薬剤設定から `mL/h` と目標投与量を双方向に計算するプロトタイプを使えます。

## できること

- 薬剤カードを複数追加
- 薬剤選択後に Excel ベースの標準 `成分量` と `希釈総量` を初期表示
- `標準設定に戻す` ボタンで初期値へ復帰
- `成分量 ÷ 希釈総量` から濃度を自動計算
- `速度から算出` または `投与量から算出` を選択して片側入力
- Excel に記載した推奨文言を参考表示
- 小数点第2位まで表示、第3位を四捨五入
- 異常値や計算不能時は `エラー` 表示

## データについて

- 薬剤マスタは `ガンマ計算アプリ開発部/ガンマ計算.xlsm` の内容をもとに手で移植しています
- 今回は面積注表示を除外しています
- モルヒネやプロポフォールのように Excel 側で標準調製が空欄のものは、プロトタイプでも手入力前提です

## スマホで使う

- Android: 公開URLを Chrome で開くと「ホーム画面に追加」または「インストール」が使えます
- iPhone: Safari の共有メニューから「ホーム画面に追加」を選びます
- PWA のオフラインキャッシュは `https://` または `http://localhost` で有効です
- `file://` で直接開いた場合、画面は表示できますが PWA 機能は一部動きません
